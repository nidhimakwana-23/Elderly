# Reports Directory

This directory stores validation, training, and evaluation reports generated by the pipeline scripts:
- `dataset_validation_report.json`: Output of `scripts/validate_dataset.py`.
- `data_preparation_report.json`: Output of `scripts/prepare_dataset.py`.
- `training_report.json`: Output of `scripts/train.py`.
- `test_evaluation_report.json` & `evaluation_summary.md`: Output of `scripts/evaluate.py`.
