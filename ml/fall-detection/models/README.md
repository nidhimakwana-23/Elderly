# Models Directory

This directory stores trained model artifact bundles generated by `scripts/train.py`.

Each bundle contains:
- `model.joblib`: The fitted scikit-learn Pipeline (imputer, standard scaler, classifier).
- `metadata.json`: Complete versioning metadata, exact feature ordering, optimal threshold, preprocessing hyperparameters, validation metrics, and package versions.

Artifact binaries (`*.joblib`) are excluded from git.
