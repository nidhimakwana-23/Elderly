# Fall Detection Datasets

This directory holds local dataset files for the fall-detection ML pipeline.

## Directory Structure

- `raw/`: Unmodified exported `PoseSequence` JSON files or converted sequence datasets.
- `interim/`: Resampled and normalized sequence cache generated by `prepare_dataset.py`.
- `processed/`: Temporal feature matrices, window manifests, and split assignments generated for training and evaluation.

> [!NOTE]
> All data in `raw/`, `interim/`, and `processed/` are excluded from version control to respect subject privacy and avoid checking large datasets into git.
